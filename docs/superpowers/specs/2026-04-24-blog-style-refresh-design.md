# pio blog: приближение к zine-стилю sereja.tech

**Дата:** 2026-04-24
**Репо:** `vedulix/blog` (Beautiful Jekyll)
**Референс:** https://sereja.tech/blog/claude-code-techno-strudel-mcp/

## Цель

Сделать визуал постов и главной спокойнее и уже, ближе к референсу `sereja.tech/blog`, не трогая Jekyll-инфраструктуру и навбар/сайдбар с аватаром.

## Скоуп

### 1. Пост — «V3»

- Ширина колонки контента: **620px** (переопределяем Bootstrap-сетку через CSS)
- `body` 16px (1rem), line-height 1.7 — шрифты `Lora` / `Open Sans` остаются
- Заголовки меньше: h1 1.75rem, h2 1.375rem, h3 1.125rem
- **Теги** переносим из-под статьи (`blog-tags` внизу) в шапку поста, под `post-meta`
- Теги оформляем как пиллы: 1px чёрная рамка, закруглённые, hover — инверсия (чёрный фон, белый текст)
- `<pre>` — 1px тёмная рамка (`#222`), без серой заливки
- Callout-блоки: класс `.callout`, модификаторы `.callout.insight` (зелёный left-border), `.callout.warning` (красный). Используются опционально в markdown через IAL: `{: .callout .insight}`

### 2. Главная — «H1»

- Ширина feed-колонки: **680px**
- Карточка поста:
  - thumbnail 7rem (112px), без `filter: grayscale(40%)`
  - бордер между карточками `1px solid #f2f2f2` (тоньше, чем сейчас)
  - `subtitle` цвет `#777`, вес 400
  - `post-meta` цвет `#999`, размер 0.8125rem
- Прячем `[Read More]` и блок тегов под карточкой (excerpt остаётся — он даёт превью)
- После последней карточки: тонкий горизонтальный разделитель + plain-ссылка **«Все посты →»**, ведёт на `/archive/`

### 3. Новая страница `/archive`

- Компактный список всех постов, сгруппирован по годам
- Формат строки: `дата · заголовок` (дата 0.8125rem, заголовок — ссылка)
- Группировка — Liquid-итерация по `site.posts` с группировкой по году публикации
- Ширина колонки 600px, layout `page`

## Вне скоупа (обсудим позже)

- Sticky-сайдбар «Последние» на вебе (≥1100px)
- Ссылка «Архив» в навбаре (пока доступ к архиву — через ссылку под feed)
- Мобильные tweaks за рамки базовой адаптивности Beautiful Jekyll

## Файлы

| Файл | Действие |
|---|---|
| `assets/css/overrides.css` | **новый** — все стилевые правки для поста, главной, архива |
| `_config.yml` | включить `site-css: ["/assets/css/overrides.css"]` |
| `_layouts/post.html` | перенести блок тегов из-под `<article>` наверх — вставить сразу после `{% include header.html type="post" %}`, чтобы теги появлялись под шапкой поста (заголовок + subtitle + post-meta) до самой статьи. `_includes/header.html` не трогаем. |
| `_layouts/home.html` | после `.posts-list` добавить блок «Все посты →» (plain-ссылка на `/archive/`) |
| `archive.md` | **новая** страница в корне, frontmatter: `layout: page`, `title: Все посты`, `permalink: /archive/` |

## Что не трогаем

- `_includes/head.html`, `_includes/footer.html`, `_includes/header.html` кроме позиции тегов
- `_layouts/base.html`, `_layouts/default.html`, `_layouts/page.html`, `_layouts/minimal.html`
- Навбар, сайдбар с аватаром, футер, social-links, staticman
- Страницы `/me`, `/projects`, `/tags`, `feed.xml`
- Markdown-файлы постов в `_posts/` (кроме демо-добавления callout, если захочется)
- Тему Beautiful Jekyll (никаких форков/переопределений layout-ов `base`/`default`)

## Риски

- CSS-override ширины колонки через `!important` поверх Bootstrap-сетки — возможны конфликты на мобильных брейкпоинтах; протестировать на нескольких ширинах
- Kramdown IAL `{: .callout .insight}` применяется к следующему блоку — проверить, что он корректно оборачивает параграф с вложенным текстом и не ломает markdown-парсинг
